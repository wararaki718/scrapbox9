# 分割時系列分析サンプルの設計

## 目的

`math_sample/simulate-intempted-time-series/` に、介入時点の前後で水準と傾きがどう変化したかを学べる、小規模な分割時系列分析のPythonサンプルを作成する。実データは使用せず、サンプル内で再現可能なデータを生成する。

## 採用する方法

介入前後の単純な平均値比較では時間傾向を区別できず、自己相関まで考慮する時系列モデルはこのサンプルの範囲に対して複雑である。そのため、時間傾向、介入後フラグ、介入後経過時間を説明変数とする分割回帰を採用する。

時点 \(t\)、介入開始時点 \(t_0\)、結果 \(Y_t\) に対して、次の線形モデルを用いる。

\[
Y_t = \beta_0 + \beta_1 t + \beta_2 I(t \ge t_0) + \beta_3 (t-t_0)I(t \ge t_0) + \epsilon_t
\]

\(\beta_2\) は介入時の水準変化、\(\beta_3\) は介入後の傾きの変化を表す。介入前の傾きは \(\beta_1\)、介入後の傾きは \(\beta_1+\beta_3\) となる。推定値は介入との関連を示すものであり、交絡要因や自己相関を扱わないため、因果効果を保証するものではない。

## データと出力

- 月次の小規模な合成データをコード内で決定論的に作成する。
- 系列の途中に介入時点を設け、介入前後で異なる水準・傾きが現れるデータとする。
- `statsmodels` のOLSでモデルを適合し、係数と主要な統計量をコンソールに表示する。
- 観測値、モデルの推定値、介入時点を図示し、実行ディレクトリに `interrupted_time_series.png` として保存する。

## プロジェクト構成

```text
math_sample/simulate-intempted-time-series/
├── README.md
├── main.py
└── requirements.txt
```

- `main.py` は小さな関数群で構成し、クラスや汎用データ読み込み機能は導入しない。
- `requirements.txt` には `numpy`、`statsmodels`、`matplotlib` を記載する。
- `README.md` には手法、係数の解釈、依存関係の導入、実行方法、制約を記載する。

## `main.py` の関数構成

- `generate_sample_data()` は時系列、観測値、介入インデックスを返す。
- `build_design_matrix()` は切片、時間、介入後フラグ、介入後経過時間の設計行列を作る。
- `fit_interrupted_time_series()` は設計行列と観測値からOLSモデルを適合する。
- `print_results()` は水準変化・傾き変化の推定値と統計量を説明付きで表示する。
- `plot_results()` は観測値とモデル適合値、介入位置を可視化してPNGを保存する。
- `main()` は上記処理を順に呼び出すエントリーポイントとする。

## 実行・確認

対象ディレクトリで `pip install -r requirements.txt` の後に `python main.py` を実行する。推定結果が表示され、PNGが生成されることを確認する。READMEの手順と説明も実装内容に一致させる。
